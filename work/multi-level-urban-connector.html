The Curator — Youth-Oriented Urban Connector

A graduation project addressing urban fragmentation through spaces for movement, encounter and youth-oriented public activity.

Type
Graduation Project / Architecture
Location
Wadi Abdoun · Amman, Jordan
Year
2026
Role
Academic design
Original portfolio / Architectural project imagery
Selected Project
Graduation Project / Architecture

Context

Amman's topography and car-oriented growth contribute to fragmented pedestrian networks and disconnected public spaces. The Curator explores how architecture might respond to these conditions.

Design development

The work uses multi-level connections and a distributed program organized around creating, playing and gathering. Research, spatial mapping, concept diagrams and physical models inform the proposal.

Representation

The published portfolio includes site analysis, diagrams, renders, architectural plans and a physical study model. The selected images here come from that portfolio.

The portfolio presents this project as The Curator: Youth-Oriented Urban Connector. Academic advisor: Dr. Yaman Al-Hanawi. These photographs are sourced from the 2026–2027 architecture portfolio supplied for the website.
